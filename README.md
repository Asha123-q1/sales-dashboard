# Sales Performance Dashboard

Interactive Power BI dashboard tracking sales trends, profitability and monthly performance.

## Tools
Power BI, DAX, Power Query

## Features
- Custom DAX measures
- Slicers and drill-through reports
- Dynamic tooltips for self-serve analysis
